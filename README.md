# Brandon Pautler – portfolio site

A one-page static site (no build step), hosted with GitHub Pages. The animated
background (LED board, magnetic field, workbench) is drawn on a canvas in
`index.html`; there are no other scripts or dependencies.

## Photos

Put JPGs in the `images/` folder with these exact names (no extra `images` prefix).
A photo slot stays hidden, or shows a placeholder on the bench, until its file exists.

| File | What to show |
|---|---|
| `images/microscope.jpg` | The assembled microscope (labelled figure) |
| `images/headphones-done.jpg` | The finished repair (sits on the bench) |
| `images/headphones-mold.jpg` | The mold (sits on the bench) |
| `images/led-board.jpg` | Optional: final LED board, close-up |
| `images/led-board-revisions.jpg` | Optional: board revisions side by side |
| `images/mri-inductor.jpg` | Optional: an air-core inductor |
| `images/mri-enclosure.jpg` | Optional: the enclosure |

Landscape photos (4:3) around 1600 px wide work best. Keep each under ~500 KB.

## Updating the résumé

Replace `Brandon_Pautler_Resume.pdf` with the new version, keeping the same file name.
