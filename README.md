# Brandon Pautler – portfolio site

A one-page static site (no build step). Hosted with GitHub Pages.

## Adding photos

Put JPGs in the `images/` folder with these exact names. A photo slot stays hidden until its file exists.

| File | What to show |
|---|---|
| `images/microscope.jpg` | The assembled microscope |
| `images/led-board.jpg` | Final LED board, close-up |
| `images/led-board-revisions.jpg` | The board revisions side by side |
| `images/mri-inductor.jpg` | An air-core inductor (once you've wound one) |
| `images/mri-enclosure.jpg` | The enclosure, CAD render or print |
| `images/headphones-mold.jpg` | The mold around the solder joint |
| `images/headphones-done.jpg` | The finished repair |

Landscape photos around 1600 px wide work best. Keep each under ~500 KB.

## Updating the résumé

Replace `Brandon_Pautler_Resume.pdf` with the new version, keeping the same file name.
